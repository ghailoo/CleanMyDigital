# Screenshots

The README links these five files. They're commented out there until the images
exist, so the page doesn't show broken images. Uncomment both blocks once they land.

| `quality-check.png` | A spectrogram from **Check Quality** — best if it's a transcode, so the brickwall is visible. |

Capture with ⌘⇧4 then Space to get the window with its shadow, in light mode.
